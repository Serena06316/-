# 内置公共题库（question-banks/）

放在这个目录下的题库文件会成为**内置公共题库**：部署后所有访问者都会在应用首页
「我的文件夹」下方看到，结构与用户自建题库一致（**科目文件夹 → 题集文件**）。

## 添加题库（手机 / 网页版即可，共 3 步）

1. 在 GitHub 上进入 `question-banks/` 目录，点右上角 **Add file → Create new file**，
   输入 `病理生理学/题集名.json`（用 `/` 会自动创建文件夹），粘贴题库内容提交；
   或点 **Add file → Upload files** 上传 `.json` 文件（先用**进入** `question-banks/病理生理学/`
   再上传，文件才会放进对应科目文件夹）。
2. 提交后**等 1-2 分钟**（GitHub Pages 更新）。
3. 打开刷题网页，首页点「内置公共题库」区的**「刷新」**按钮即可看到。

> 不需要任何清单文件：应用在没有 `manifest.json` 时会自动调用 GitHub 接口
> 扫描本目录发现题库。若你的网络访问 GitHub 接口不稳定，也可以选择
> 上传 `manifest.json` 清单（或部署 `.github/workflows/` 里的 Action 自动维护），
> 清单存在时优先使用清单。

## 文件规则

- **文件夹名 = 科目名，文件名（去掉扩展名）= 题集名**，支持中文。
- 支持格式：**.json（推荐）/ .txt / .csv / .docx**，均为 UTF-8 编码：
  - `.json`：题目数组，或 `{"title": "题集名", "questions": [...]}`；每题含
    `question / type(single|multiple|judge) / options / answer / explanation / chapter`，
    格式与应用「使用说明」中的 JSON 题库格式完全一致；
  - `.txt` / `.csv` / `.docx`：与应用导入功能的对应格式一致（`---` 分隔题目、
    `答案: B`、`解析:` 等，详见应用「使用说明」）。
  - 想从 Word 得到标准 `.json`：先在应用里导入 Word 题（自动转换），
    再到题集页点「导出题库 JSON」按钮即可。
- **文件夹必须至少包含一个题库文件才会显示**（GitHub 也不保留空文件夹）。
- 修改文件名 / 文件夹名 / 移动文件，在访问者端相当于出现一个新题集
  （旧题集及其练习记录会被清理）。

## 清单方式（可选）

`manifest.json` 由 `tools/generate_manifest.py` 生成（GitHub Action 会自动维护）：
推送涉及本目录的改动后约 1 分钟，Action 会自动重新生成并提交。
不想用 Actions 也可手动维护，格式：

```json
{
  "app": "tiku-public",
  "folders": [
    {
      "name": "病理生理学",
      "sets": [
        { "name": "病生选择题（前半）", "file": "question-banks/病理生理学/病生选择题（前半）.json", "count": 511 }
      ]
    }
  ]
}
```

## 注意事项

- 每个访问者第一次打开某个公共题集时才会下载该文件（按需缓存）；
- 访问者在该题集上的练习记录、错题、收藏保存在他们各自的浏览器中，与仓库无关；
- 删除某个文件后，访问者端刷新目录时该题集不再显示（其相关练习记录会一并清理）。
